# 第一档 · 同一个 WiFi（5 分钟，零成本）

> 最适合：在家、在办公室，手机和电脑连同一个路由器。
> 优点：不用域名、不用花钱、延迟 1–5 毫秒。
> 缺点：出了这个 WiFi 就断了。

---

## 1. 让服务监听在局域网

服务必须监听 `0.0.0.0`，不能是 `127.0.0.1`，否则手机连不上。

```bash
# 参考实现
python3 server/main.py --host 0.0.0.0 --port 8899
```

验证：

```bash
curl -s http://127.0.0.1:8899/api/health
```

## 2. 查电脑的局域网 IP

**macOS**

```bash
ipconfig getifaddr en0     # WiFi
ipconfig getifaddr en1     # 有线/部分机型
```

**Linux**

```bash
ip route get 1.1.1.1 | awk '{print $7; exit}'
```

**Windows**

```powershell
ipconfig | findstr IPv4
```

拿到类似 `192.168.1.3`。如果是 `169.254.x.x`，说明没拿到 DHCP，先查路由器。

## 3. 手机连上

1. 手机确认连的是**同一个 WiFi**（注意别是 5G 蜂窝、也别是访客网络）
2. Cat 面板 → 设置 → 地址填 `http://192.168.1.3:8899`，口令填服务端生成的 token
3. 点「测试连接」，应显示服务名（`/api/health` 返回的 `name`）

## 4. 连不上时的排查顺序

按这个顺序，一步一验，别跳：

1. **电脑上自测通不通**
   `curl http://127.0.0.1:8899/api/health` —— 不通是服务没起或端口错
2. **电脑上用自己的局域网 IP 自测**
   `curl http://192.168.1.3:8899/api/health` —— 127.0.0.1 通但这步不通 → 服务只监听了本地回环，改 `0.0.0.0`
3. **手机浏览器直接打开**
   `http://192.168.1.3:8899/api/health` —— 浏览器能开、面板不能 → 是面板设置问题（地址少了 `http://`、端口写错）
4. **手机浏览器也打不开** → 网络层问题：
   - 手机是否连同一 WiFi（最常见）
   - 路由器是否开了「AP 隔离 / 客户端隔离」—— 开了就必须关掉
   - 电脑防火墙是否拦了该端口（macOS：系统设置 → 网络 → 防火墙）
   - 公司/酒店 WiFi 常禁止设备互访，换手机热点试

## 5. IP 会变怎么办

路由器一般按 DHCP 分配，重启后可能变。两个解法：

- 路由器里给电脑做 **IP 绑定 / 静态租约**（推荐，一次搞定）
- 或者每次变了就改一下手机里的地址（麻烦，但能用）

## 验收标准

- 手机浏览器打开 `http://<IP>:8899/api/health` 能看到 JSON
- 面板「测试连接」显示服务名
- 说一句话，状态文字出现文字流，发送后能收到回复

三条都过，这一档就算通了。之后想在外面也用，看 [setup-ipv6-ddns](setup-ipv6-ddns.md) 或 [setup-frp](setup-frp.md)。
