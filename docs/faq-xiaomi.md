# 小米 / 红米 / HyperOS 用户必读

> 这不是 bug，这是小米的默认设置。三件事，全都会让你以为"这软件坏了"。

---

## 1. 桌面组件加不上（点了没反应，连弹窗都没有）

**症状**：设置里点「添加到桌面」，什么都不发生。

**原因**：小米把「添加桌面项目 / 创建快捷方式」这个系统操作映射成 **MIUIOP `10017`**（对应 Android 的 `OP_INSTALL_SHORTCUT`），**默认值是 `ignore`**。系统在 App 请求添加时静默拦截，不报错、不弹窗 —— 所以看起来像"点了没用"。

**解法 A（不用电脑）**

设置 → 应用管理 → Cat Panel → 权限管理 → 找「**桌面快捷方式**」（有的版本叫「添加桌面项目」或「创建快捷方式」）→ 允许。

然后回 App 再点一次「添加到桌面」。

**解法 B（有 adb）**

```bash
adb shell cmd appops set com.a07.catpanel 10017 allow
adb shell cmd appops get com.a07.catpanel 10017    # 复核，应显示 allow
```

### ⚠️ 铁律：每次装包都会重置

`adb install -r`（覆盖安装）会把这个 appop 打回 `ignore`。

**所以：装完新版本 → 必须再放行一次 → 否则"添加桌面"必然失败。**

这就是"昨天还能加、今天就加不上"的唯一原因。跟版本、跟代码都无关。

## 2. 悬浮窗开了但不显示

**原因**：HyperOS 的「后台弹出界面」和「悬浮窗」是两个独立开关。

**要做**：

1. 设置 → 应用管理 → Cat Panel → **显示悬浮窗** → 允许
2. 设置 → 应用管理 → Cat Panel → 权限管理 → **后台弹出界面** → 允许
3. 设置 → 应用管理 → Cat Panel → **省电策略** → 改成「无限制」
4. 最近任务里把 Cat Panel **下拉锁定**（加锁图标），防止清理时被杀

第 3、4 步不做，App 会在几分钟后被系统杀掉，表现为"昨天还好好的，今天一叫没反应"。

## 3. 说一句话，立刻被切断 / 显示"没有可用的语音识别服务"

**原因**：HyperOS 会限制后台应用的麦克风。悬浮窗是后台状态。

**要做**：

1. 麦克风权限授予 Cat Panel（首次会弹）
2. 关闭「麦克风使用提醒」的干扰：设置 → 隐私 → 麦克风 → 不要禁止 Cat Panel
3. 如果提示「这台手机暂时没有可用的语音识别服务」—— 那是系统自带的语音识别被禁用了：设置 → 应用管理 → 显示系统应用 → 「语音服务 / Google 语音服务」→ 启用

> 本项目的语音转写**不走系统语音服务**（走你自己的服务端），所以第 3 条只在用系统识别时才需要。

## 4. 其他常见问题

**Q：手机重启后悬浮窗不出现了**
开机自启被限制。设置 → 应用管理 → Cat Panel → 自启动 → 打开。

**Q：连不上，一直提示网络错误**
先看 [`setup-lan.md`](setup-lan.md) 第 4 节的排查顺序。小米的「WLAN 助理」会在 WiFi 信号弱时自动切流量，导致局域网地址突然不可达 —— 设置 → WLAN → WLAN 助理 → 关闭「自动切换移动数据」。

**Q：能不能像小爱同学那样一直听着？**
不能，也不建议。持续录音既费电也涉及隐私。本项目的设计是**按住说话 / 点一下说，说完就停**。
