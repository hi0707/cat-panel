# Tailscale（全球通用 · 零配置组网）

> 最适合：**中国大陆以外**的用户，或者不想碰路由器、不想买服务器、想在任何网络下都能用的人。
> 优点：装两个客户端、登同一个账号，就有固定地址；自动打洞，打不通自动走中转；不用域名、不用备案、不用开端口。
> 缺点：**中国大陆用户体验较差** —— 登录入口和默认中转都在境外，常卡在登录或被迫走海外中转（延迟 200ms+）。国内用户请看本文末尾的「国内怎么用」。

---

## 1. 装

**手机（Android）**

- 有 Google Play：直接搜 Tailscale
- 没有：到 <https://tailscale.com/download/android> 下 APK，或从 GitHub Releases sideload

**电脑**

- macOS：`brew install --cask tailscale`，或官网下载
- Linux：`curl -fsSL https://tailscale.com/install.sh | sh`
- Windows：官网安装包

## 2. 登录同一个账号

两端都登录**同一个账号**（Google / GitHub / Microsoft / 邮箱均可）。

登录后两端会各拿到一个 `100.x.y.z` 的地址 —— 这个地址**永久固定**，换 WiFi、换网络都不变。

## 3. 查电脑的 Tailscale 地址

**macOS / Linux**

```bash
tailscale ip -4
# 100.101.102.103
```

**Windows**

```powershell
tailscale ip -4
```

## 4. 服务监听所有地址

```bash
python3 server/main.py --host 0.0.0.0 --port 8899
```

## 5. 手机里填

```
http://100.101.102.103:8899
```

口令照常填服务端生成的 token。

**注意**：地址是 `100.x`，**不是**你家局域网的 `192.168.x`。这两个不冲突，Tailscale 是叠加在现有网络之上的一层。

---

## 6. 验证通了没

手机上（**关掉 WiFi 用流量**更能说明问题）：

```bash
# 浏览器打开
http://100.101.102.103:8899/api/health
```

看到 JSON 就通了。

打不开时按顺序查：

1. **两端 `tailscale status` 是否都显示对方 online** —— 不在线就是没登录成功
2. **电脑上 `curl http://100.101.102.103:8899/api/health`** —— 本机都不通是服务没起或只听 127.0.0.1
3. **电脑防火墙**是否拦了 100.x 网段的入站（macOS：系统设置 → 网络 → 防火墙 → 选项）
4. **手机是否开了「始终开启 VPN」的其他应用**（另一家 VPN 会抢路由表）

---

## 7. 安全说明（要知道）

- Tailscale 的设备之间是 **WireGuard 加密**，端到端
- 默认策略是**同一账号下所有设备互通**。如果你账号里加了别人的设备，别人也能访问你的 8899 端口 —— 到 admin 后台用 ACL 收紧，或者干脆不共享账号
- 面板服务**自己仍然要校验口令**。组网不是鉴权

## 8. 国内怎么用（中国大陆用户）

Tailscale 在国内的三个实际障碍：

1. **登录入口在境外**（`login.tailscale.com`）—— 经常卡住或直接连不上
2. **默认中转（DERP）在境外** —— 打洞失败时走海外中转，延迟 200ms 以上，音频会卡
3. **运营商对 UDP 的限制** —— 打洞成功率不稳定

社区里成熟的绕法有两种：

**A. 自建 headscale（控制面换到国内 VPS）**

客户端仍用官方 Tailscale App，只是把登录地址换成你自己的服务器。这样登录不卡，但中转仍在境外，需要配合 B。

**B. 自建 DERP 中转**

在国内 VPS 上跑 `derper`，把中转节点换到国内。延迟从 200ms 降到 30–60ms。

两条都做完，体验就接近国内组网工具了 —— 但**这已经不算"零配置"了**，配置量接近自建 frp。

**C. 换用国产方案**

国内网络环境下，还有两个同类工具值得看（本项目不背书，只列出）：

- **EasyTier** — 国产开源（Rust），中文文档，自带公共发现节点，也支持自建节点
- **ZeroTier** — 老牌，国内可自建 moon 节点改善连通性

> 如果你在国内、且不想折腾：直接用 [setup-ipv6-ddns](setup-ipv6-ddns.md)（家宽 IPv6 直连）或 [setup-frp](setup-frp.md)（小服务器中转），比在 Tailscale 上折腾省事。

## 为什么仍然把这一档留着

因为**这个项目是给全世界的**。

对欧美、东南亚、日韩的用户来说，Tailscale 是这几档里**最简单的**：装两个 App、登一个账号、完事。不用碰路由器、不用买服务器、不用配 DNS。

所以文档的定位是：**给用户四个选项，让他按自己所在网络选**，而不是替他决定。国内用户看到第 8 节的提示自然会选别的。

---

## 验收标准

- 两端 `tailscale status` 互相 online
- 手机断 WiFi 用流量，浏览器能打开 `http://100.x.x.x:8899/api/health`
- 面板「测试连接」显示服务名
- 说一句话能收到回复
