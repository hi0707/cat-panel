# Cat Panel · 手机上的 Agent 输入层

> 在任意界面唤出一个悬浮条，说一句话，直接发给**你自己的** Agent，回复就地显示。
> 不切换 App，不打开聊天框，不经过任何第三方服务器。

---

## 它解决什么问题

现在用手机连 Agent，路径都是三步：解锁 → 打开飞书/微信 → 找到那个对话框 → 打字或按住说话 → 等回复 → 再切回原来在做的事。

**每一次都被打断。** 真正的成本不是打字，是"离开当前屏幕"这个动作 —— 你在看资料、在记笔记、在跟人对话，为了问一句 AI，整块注意力被切走。

Cat Panel 把这条路压成一步：**在任何界面上，点一下悬浮的麦克风，边说边出字，一松手就发出去，回复直接出现在原地。**

## 它不是什么

- **不是一个 Agent。** 它不自带模型、不做推理、不存你的对话在云端。它只是「嘴」和「耳朵」。
- **不是聊天软件。** 没有好友、没有服务器、没有账号体系。
- **不会绕过任何平台的规则。** 它不去抓别人的 App、不做自动填入、不用无障碍服务。

## 它是怎么工作的

```
手机：悬浮条（录音 + 实时转写 + 显示回复）
  │  HTTPS / HTTP，带口令
  ▼
你自己的服务（跑在你的电脑 / NAS / 小服务器上）
  │
  ▼
你自己的 Agent（OpenClaw / 自建 LLM / n8n / 任何实现了 3 个接口的东西）
```

**关键点：中间那一层是「你自己的」。** 你的语音、你的对话内容，只经过你自己的机器。这个项目不提供、也不需要任何中心服务器。

## 三个接口就能接

任何服务只要实现这三个 HTTP 接口，就能和面板配合：

| 接口 | 作用 | 必需 |
|---|---|---|
| `GET /api/health` | 连通性检查 | ✅ |
| `POST /api/text` | 发一句话，拿回回复 | ✅ |
| `POST /api/asr` | 语音转文字（也可在手机上做） | 可选 |

完整契约见 [`docs/protocol.md`](docs/protocol.md)。

## 怎么让它连上你

项目**不绑定任何一种组网方案**。你只需要给面板一个「能访问到的地址 + 口令」。选哪条路取决于你在哪用：

| 场景 | 方案 | 文档 |
|---|---|---|
| 在家 / 办公室 | 同一个 WiFi，填局域网 IP | [setup-lan](docs/setup-lan.md) |
| **中国大陆以外，或不想折腾路由器** | **Tailscale（装两个 App 就完事）** | [setup-tailscale](docs/setup-tailscale.md) |
| 中国大陆，在外面也想用，不想花钱 | IPv6 + DDNS 直连 | [setup-ipv6-ddns](docs/setup-ipv6-ddns.md) |
| 到处都要用，要稳定 | 小服务器 + frp | [setup-frp](docs/setup-frp.md) |

> **中国大陆用户注意**：Tailscale 的登录入口和默认中转在境外，体验较差（详见 [setup-tailscale §8](docs/setup-tailscale.md)）。国内优先看 IPv6 或 frp 两档。

> English docs: [README.en.md](README.en.md) · 中文为主，英文版补齐中。

## 装到手机上

1. 到 [Releases](../../releases) 下载最新的 `.apk`
2. 安装（安卓 8.0 以上）
3. 打开后按引导填地址和口令、给悬浮窗和麦克风权限

想自动更新：装 [Obtainium](https://github.com/ImranR98/Obtainium)，把本仓库地址粘进去，之后每次发版它会自己更新。

**不需要 USB，不需要连电脑装。**

## 已知限制（诚实版）

- **只有安卓。** iOS 不允许跨应用悬浮录音，"任意界面说话"在 iPhone 上做不到（最多锁屏小组件或输入法）。
- **首次授权有点绕。** 悬浮窗 + 麦克风 + 关电池优化，三步都得手动给，系统不让一键。
- **小米/红米用户必看** [`docs/faq-xiaomi.md`](docs/faq-xiaomi.md)：桌面组件加不上不是 bug，是系统把权限默认拒了，而且每次装包都会重置。
- **音频走网络。** 如果你的服务在外网，语音要绕一圈；局域网内延迟可以忽略。

## 仓库结构

```
cat-panel/
├── app/               安卓客户端（Kotlin + Compose）
├── server/            参考后端（Python 3 标准库，零依赖）
├── docs/              接口契约 + 四种连通方案 + 小米 FAQ
└── .github/workflows/ 打 tag 自动编译出 APK
```

自己编译（装了 Android SDK 就能跑）：

```bash
./gradlew :app:assembleDebug
# 产物 app/build/outputs/apk/debug/app-debug.apk
```

只改服务端、不碰客户端的话，`cd server && python3 main.py` 就够。
